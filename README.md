## Featured Projects

<details open>
<summary><b>🧴 DermalScan</b> — AI-powered skin age & condition classifier</summary>
<br/>

`Python` `TensorFlow` `EfficientNetB0` `OpenCV` `Streamlit`

> Built end-to-end at Infosys Springboard — a dermatology classifier that actually holds up across real-world lighting and skin tones.

- EfficientNetB0-based classifier reaching **~96% accuracy** across 4 skin condition classes
- Real-time inference pipeline via **OpenCV + Streamlit**, cutting manual review time by ~70%
- Automated ROI extraction using Haar Cascades for stable detection across varied facial structures & lighting

</details>

<details>
<summary><b>💻 Vrutti</b> — lightweight native code editor</summary>
<br/>

`Rust` `C++` `Tauri` `Lit`

> Rebuilt from the ground up as a lightweight, native desktop editor — trading browser overhead for a Rust + C++ core wrapped in a Tauri shell.

- Tauri-powered native shell keeps the app lightweight, fast, and cross-platform
- Rust + C++ core handles performance-critical editing and file operations
- Lit-based web components for a fast, reactive, dependency-light UI
- Syntax highlighting, integrated terminal, and a minimal footprint by design

</details>
